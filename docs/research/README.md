## Lo que buscamos aprender

1. ¿Con qué frecuencia necesitan cifras de la ENA o la ENAHO, y para qué entregable?
2. ¿Cómo las consiguen hoy y cuánto tiempo o dinero les cuesta?
3. ¿Qué les preocupa de usar IA para esto?
4. ¿Pagarían? ¿Cuánto, y quién paga (ellos o su institución)?
